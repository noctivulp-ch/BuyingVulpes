# BuyingVulpes

Listas de compras por tienda. Catálogo de productos con precio por medida,
lista con casilla que pasa cada artículo al carrito, presupuesto a la vista,
y un desglose en PDF de cada compra, archivado en un calendario.

Flutter · Riverpod · SQLite · [Wulfenite-UI](../%23Libs/wulfenite_ui/).

```bash
flutter run -d linux
flutter test
```
